# Days in Month Program in C

This is a beginner-friendly C program that displays the number of days in a month using if-else conditions.

## Features
- Checks 31 days months
- Checks 30 days months
- Handles February separately
- Invalid month detection

## Concepts Used
- if-else statements
- Logical operators (||)
- User input

## Month Logic

### 31 Days Months
1, 3, 5, 7, 8, 10, 12

### 30 Days Months
4, 6, 9, 11

### February
28 or 29 days

## Sample Output

Enter month number:
8

31 days
